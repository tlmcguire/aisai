# The language marks

The icons in this folder are the file icons of the
[Material Icon Theme for Visual Studio Code](https://github.com/PKief/vscode-material-icon-theme),
used under the MIT licence. They are the marks that Visual Studio Code shows
for a language, so the files of a project look the way they look in an editor.

The marks of Kotlin and of `.env` come from
[Simple Icons](https://simpleicons.org), used under CC0 1.0, because the theme
draws Kotlin with a gradient and has no mark for `.env`.

Every file is named after the language it stands for, so `python.svg` is the
mark of Python and `csharp.svg` the mark of C#. The names of the languages are
in `src/lib/langicons.ts`.
